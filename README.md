# streamlitApp
This application utilizes a free book API to display different data about a random set of books.

# What API?
The one provided by openbookrank.com.

# What data is displayed?
Awards won by the book, the year the book was released, and the rating score of the book out of 10.

# What is offered in the application.

The application only offers a limited range of books, about 5 books are utilized, but their title is utilized in the functionality of the API to receive information about the books.

The books and their information are displayed in three different plotly charts, of which the user can choose among. 

# How to utilize the application?

This application is public by utilizing Streamlit Community Cloud, which will be below:

https://appapp-dtxzoqs2fwxs963nrbtxg8.streamlit.app/

# Recreating the Project from GitHub?

To recreate the project and view the code, you must clone or fork this repository.
Once in your IDE, you can download the respective dependencies that were utilized in this project as detailed in requirements.txt.
Afterwards, the application should run with "streamlit run streamlitApp.py"

Note: It is best to be in a python virtual environment while in development mode.
